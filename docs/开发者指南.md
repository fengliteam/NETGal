# NETGal 开发者指南

## 架构

- `NETGal.Engine`：纯 .NET 10 核心，包含项目模型、验证、指令运行时、存档校验和保护包。
- `NETGal.Studio.Windows`：Windows 原生 WPF 编辑器，不依赖浏览器或 WebView。
- `NETGal.Player.Windows`：Windows 原生 WPF 播放器。
- `NETGal.Studio.Maui` / `NETGal.Player.Maui`：面向 Windows、Android、iOS 和 Mac Catalyst 的原生 MAUI 宿主。
- `NETGal`：浏览器编辑器、静态导出和发布命令。

核心层不直接依赖 UI、音频或平台生命周期。宿主读取 `RuntimeSnapshot` 并决定如何显示场景、播放声音和保存文件。

## 构建

所有缓存可以放在仓库的 `work` 目录，避免占用 C 盘：

```powershell
$env:DOTNET_CLI_HOME = "$PWD/work/dotnet-home"
$env:NUGET_PACKAGES = "$PWD/work/nuget-packages"
dotnet build NETGal.sln -c Release
dotnet run --project tests/NETGal.Engine.Smoke -c Release
```

MAUI 目标需要在构建机安装 MAUI workload。Windows WPF 目标只需要 .NET 10 SDK 和 Windows Desktop 运行时。

## 兼容性原则

不要删除旧的场景字段。`StoryRuntime` 会优先执行 `commands`，没有指令流时继续使用 `background`、`speaker`、`text` 和 `choices`，这样旧项目无需迁移。

## 提交代码

提交前至少运行引擎编译、WPF 编译和冒烟测试。涉及发布包时，还要确认输出中没有 `game.json`，且修改 `game.pkg` 的任意字节都会被拒绝。
