# NETGal 用户手册

NETGal 是一个基于 .NET 10 的原生 GalGame/视觉小说引擎。编辑时使用 `game.json`，发布时可以生成不需要 .NET SDK 或运行时的自包含原生程序。

## 第一次运行

在仓库目录执行：

```powershell
dotnet run --project src/NETGal -- new samples/MyGame "我的第一个游戏"
dotnet run --project src/NETGal -- play samples/MyGame
```

浏览器编辑器适合快速修改剧情。Windows 原生编辑器不依赖 MAUI 工作负载：

```powershell
dotnet run --project src/NETGal.Studio.Windows -- samples/Starfall
```

## 项目文件

项目目录至少包含 `game.json` 和 `assets` 目录。旧格式使用 `scenes` 中的 `text`、`choices` 等字段；新项目还可以使用：

```json
{
  "variables": { "affection": 0 },
  "commands": [
    { "cmd": "set", "args": { "name": "affection", "value": 1 } },
    { "cmd": "text", "args": { "speaker": "优衣", "content": "你好。" } },
    { "cmd": "choice", "args": { "options": [
      { "id": "good", "text": "回应她", "next": "good-ending", "condition": "affection >= 1" }
    ] } }
  ]
}
```

支持的基础指令是 `bg`、`char`、`text`、`set`、`if`、`goto`/`jump` 和 `choice`。条件表达式支持 `==`、`!=`、`>`、`>=`、`<`、`<=` 和 `!变量`。

## 发布 Windows 游戏

发布命令会自动生成随机密钥、AES-GCM 加密的 `game.pkg`，并把密钥编译进原生播放器：

```powershell
dotnet run --project src/NETGal -- publish samples/Starfall windows Release dist/Starfall/windows
```

发布目录中的游戏不需要安装 .NET SDK 或 .NET 运行时。`game.json` 只保留在编辑工程中，不会作为明文文件复制到受保护的原生游戏目录。

## 存档

原生播放器提供保存和读取进度。存档使用 HMAC-SHA256 校验；受保护发布版使用该游戏的随机发布密钥，开发版使用项目 ID 派生密钥。存档校验可以阻止普通篡改，但不能替代服务端反作弊。

## 安全边界

AES-GCM 可以防止普通用户直接打开和修改剧情包，并能检测资源篡改。播放器必须在本机拥有解密所需信息，因此不能保证绝对防提取或绝对防反编译。浏览器静态导出天然可检查，不适合放置秘密内容。
