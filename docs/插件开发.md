# NETGal 插件开发

插件接口位于 `NETGal.Engine`，编辑器宿主可以实现 `INetGalPluginHost` 来注册新指令、菜单命令和面板元数据。`PluginCatalog.LoadFromDirectory` 会扫描项目 `plugins` 目录下的程序集。插件不应直接依赖某个 UI 框架，以便同一个插件可被 WPF、MAUI 或浏览器编辑器使用。

最小插件结构：

```csharp
public sealed class ExamplePlugin : INetGalPlugin
{
    public string Id => "example";
    public string Name => "示例插件";
    public string Version => "1.0.0";

    public void Configure(INetGalPluginHost host)
    {
        host.RegisterCommand(new PluginCommandDefinition("example", "示例指令", ["value"]));
        host.RegisterMenuItem(new PluginMenuItem("example.open", "打开示例工具"));
    }
}
```

插件 DLL 应放在项目的 `plugins` 目录，宿主启动时创建 `PluginCatalog` 并调用扫描。插件可以提供 AI、批量资源处理、外部 API 连接等能力，但不应把 API Key 写入项目文件或发布包。

## AI 辅助插件

仓库包含 `NETGal.AiPrompt` 示例项目。它只提供规范提示词和本地 JSON 解析，不默认联网，也不要求用户配置 API Key。推荐流程是：复制规范提示词到任意 AI 工具，回答 AI 的需求问题，再把 AI 返回的 JSON 指令粘贴回编辑器解析。
